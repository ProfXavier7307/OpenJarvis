# Personal-Memory

This folder is the only default place where this fork allows the assistant to read local files.

## Important

This GitHub repository is public. Do not commit private memory files here.

The `.gitignore` in this folder ignores memory files by default so your local notes stay local.

## Example local files

Create files like these on your own machine after cloning/installing:

- `Personal-Memory/profile.md`
- `Personal-Memory/projects/doa.md`
- `Personal-Memory/preferences.md`

The assistant can read paths such as `profile.md` or `projects/doa.md` through the restricted `file_read` tool.
